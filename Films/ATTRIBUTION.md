# Films Attribution

All films in this directory are Blender Foundation open movies, licensed under Creative Commons Attribution.
Films from 2006–2016 use CC BY 2.5 or CC BY 3.0. Films from 2017 onward use CC BY 4.0.
Originals were downloaded from the respective Blender open movie project sites and studio.blender.org.

The files hosted here have been transcoded to HLS with a custom HDR bitrate ladder, sprite thumbnail strips,
extracted subtitle tracks, and extracted font assets. These constitute a derivative work. All CC BY versions
permit derivatives with attribution. Attribution is provided in this file and in the per-film ATTRIBUTION files.
